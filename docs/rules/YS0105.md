# YS0105: Tamaño de grupo ignorado

| | |
|---|---|
| Severidad | Warning |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> El tamaño de grupo solo tiene efecto en compute shaders; '`…`' es un shader `…`.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0105.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `<YotsubaShaderTargets>` en el `.csproj`.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.WorkgroupSizeIgnored`).
