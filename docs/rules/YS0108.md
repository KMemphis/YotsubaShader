# YS0108: Punto de entrada duplicado

| | |
|---|---|
| Severidad | Error |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> Hay varios puntos de entrada llamados '`…`' en '`…`'. El nombre del punto de entrada debe ser único.

En inglés (idioma base del analizador): *Duplicate entry point*: There are several entry points named '`…`' in '`…`'. The name of an entry point must be unique.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.EntryPointOverloaded`).
