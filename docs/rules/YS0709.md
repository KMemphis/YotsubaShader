# YS0709: División entera por cero

| | |
|---|---|
| Severidad | Warning |
| Área | Portabilidad |
| Categoría | YotsubaShader |

## Mensaje

> La división entera por cero da un resultado indefinido en la GPU (en C# lanza una excepción).

## Contexto

Funciona en unas APIs y no en otras; se avisa según YotsubaShaderTargets.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0709.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `<YotsubaShaderTargets>` en el `.csproj`.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.IntegerDivisionByZero`).
