# YS0011: Tipo sin representación en la GPU

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> El tipo '`…`' no existe en la GPU (`…`). Usa escalares, vectores, matrices, arrays o structs de esos tipos.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.UnsupportedType`).
