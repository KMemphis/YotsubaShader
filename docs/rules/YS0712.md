# YS0712: Versión de API gráfica sin backend

| | |
|---|---|
| Severidad | Error |
| Área | Portabilidad |
| Categoría | YotsubaShader |

## Mensaje

> `…`

En inglés (idioma base del analizador): *Graphics API version without a backend*: `…`

## Contexto

Funciona en unas APIs y no en otras; se valida contra las APIs de [ShaderTargets] (Vulkan 1.3 si el shader no declara ninguna).

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.TargetWithoutBackend`).
