# YS0305: Buffer que no es struct

| | |
|---|---|
| Severidad | Error |
| Área | Recursos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es un buffer y su tipo '`…`' no es un struct. Envuelve los datos en un struct.

En inglés (idioma base del analizador): *Buffer that is not a struct*: '`…`' is a buffer and its type '`…`' is not a struct. Wrap the data in a struct.

## Contexto

Texturas, samplers y buffers: bindings y layout de memoria.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.BufferNotStruct`).
