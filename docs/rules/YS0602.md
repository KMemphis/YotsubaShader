# YS0602: Operación solo de compute

| | |
|---|---|
| Severidad | Error |
| Área | Uso por etapa |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' solo existe en compute shaders, y se usa desde el shader `…` '`…`'.

En inglés (idioma base del analizador): *Compute-only operation*: '`…`' only exists in compute shaders, and it is used from the `…` shader '`…`'.

## Contexto

Operaciones que solo existen en una etapa del pipeline.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.ComputeOnly`).
