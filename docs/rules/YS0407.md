# YS0407: Método async o iterador

| | |
|---|---|
| Severidad | Error |
| Área | Métodos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es `…`; los shaders no tienen async ni iteradores.

En inglés (idioma base del analizador): *Async method or iterator*: '`…`' is `…`; shaders have no async or iterators.

## Contexto

Funciones auxiliares que se compilan a la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.AsyncOrIterator`).
