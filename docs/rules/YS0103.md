# YS0103: Llamada directa a un punto de entrada

| | |
|---|---|
| Severidad | Error |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es un punto de entrada y no puede llamarse desde código de shader. Mueve la lógica a una función auxiliar.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.EntryPointCalled`).
