# YS0007: Miembro del vector sin [VectorComponent]

| | |
|---|---|
| Severidad | Warning |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' no es un componente del vector '`…`' y no existe en la GPU. Márcalo con [VectorComponent] o quítalo.

En inglés (idioma base del analizador): *Vector member without [VectorComponent]*: '`…`' is not a component of the vector '`…`' and does not exist on the GPU. Mark it with [VectorComponent] or remove it.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0007.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorMemberWithoutComponent`).
