# YS0211: Índice de location negativo

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> [`…`] en '`…`' usa el índice `…`; debe ser 0 o mayor.

En inglés (idioma base del analizador): *Negative location index*: [`…`] on '`…`' uses index `…`; it must be 0 or greater.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.NegativeSlotIndex`).
