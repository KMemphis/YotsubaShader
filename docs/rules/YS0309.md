# YS0309: Location en un recurso

| | |
|---|---|
| Severidad | Error |
| Área | Recursos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es un recurso y tiene [`…`]. Los recursos se enlazan con [Binding]/[DescriptorSet], no con locations ni semánticas.

## Contexto

Texturas, samplers y buffers: bindings y layout de memoria.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.LocationOnResource`).
