# YS0210: Render target fuera de rango

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> El render target `…` de '`…`' no existe; los índices válidos son 0 a 7.

En inglés (idioma base del analizador): *Render target out of range*: The render target `…` of '`…`' does not exist; valid indices are 0 to 7.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.RenderTargetRange`).
