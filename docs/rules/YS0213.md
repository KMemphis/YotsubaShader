# YS0213: Array de interfaz sin longitud

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es un array en la interfaz y su longitud no se conoce. Indica la longitud con [ArrayLength(n)].

En inglés (idioma base del analizador): *Interface array without a length*: '`…`' is an array in the interface and its length is unknown. Specify the length with [ArrayLength(n)].

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.InterfaceArrayLength`).
