# YS0402: Parámetro ref, in u out en una función auxiliar

| | |
|---|---|
| Severidad | Error |
| Área | Métodos |
| Categoría | YotsubaShader |

## Mensaje

> El parámetro '`…`' de '`…`' es '`…`'; las funciones auxiliares todavía no admiten parámetros por referencia. Devuelve el valor.

En inglés (idioma base del analizador): *ref, in or out parameter in a helper function*: The parameter '`…`' of '`…`' is '`…`'; helper functions do not support reference parameters yet. Return the value instead.

## Contexto

Funciones auxiliares que se compilan a la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.RefParameter`).
