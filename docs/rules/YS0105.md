# YS0105: Tamaño de grupo ignorado

| | |
|---|---|
| Severidad | Warning |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> El tamaño de grupo solo tiene efecto en compute shaders; '`…`' es un shader `…`.

En inglés (idioma base del analizador): *Group size ignored*: The group size only has an effect in compute shaders; '`…`' is a `…` shader.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0105.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.WorkgroupSizeIgnored`).
