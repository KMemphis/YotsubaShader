# YS0010: Valor inicial no constante

| | |
|---|---|
| Severidad | Warning |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> El valor inicial de '`…`' no es constante; en la GPU el componente empieza en 0.

En inglés (idioma base del analizador): *Non-constant initial value*: The initial value of '`…`' is not constant; on the GPU the component starts at 0.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0010.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorNonConstantInitializer`).
