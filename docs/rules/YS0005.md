# YS0005: Componentes con tipos distintos

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> Los componentes del vector '`…`' tienen tipos distintos (`…` y `…`). Usa el mismo tipo en todos.

En inglés (idioma base del analizador): *Components with different types*: The components of the vector '`…`' have different types (`…` and `…`). Use the same type for all of them.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorMixedTypes`).
