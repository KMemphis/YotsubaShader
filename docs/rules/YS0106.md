# YS0106: Varias etapas en un método

| | |
|---|---|
| Severidad | Error |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' tiene más de un [ShaderStage]. Un punto de entrada pertenece a una sola etapa.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.MultipleStages`).
