# YS0004: Falta un índice de componente

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> Al vector '`…`' le falta el componente `…`; los índices deben ser consecutivos desde 0.

En inglés (idioma base del analizador): *Missing component index*: The vector '`…`' is missing component `…`; indices must be consecutive starting at 0.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorMissingIndex`).
