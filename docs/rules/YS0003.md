# YS0003: Índice de componente repetido

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> El índice `…` está repetido en el vector '`…`'. Cada componente necesita un índice distinto.

En inglés (idioma base del analizador): *Duplicate component index*: Index `…` is repeated in the vector '`…`'. Each component needs a distinct index.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorDuplicateIndex`).
