# YS0504: Creación de objeto sin usar

| | |
|---|---|
| Severidad | Error |
| Área | C# sin traducción |
| Categoría | YotsubaShader |

## Mensaje

> El 'new `…`(...)' no se usa; en la GPU no tiene efecto. Asígnalo o quítalo.

En inglés (idioma base del analizador): *Unused object creation*: The 'new `…`(...)' is not used; it has no effect on the GPU. Assign it or remove it.

## Contexto

Construcciones de C# que no existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.UnusedObjectCreation`).
