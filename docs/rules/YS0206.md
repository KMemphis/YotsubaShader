# YS0206: Atributos de interfaz en conflicto

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' tiene a la vez [`…`] y [`…`]. Un miembro de la interfaz lleva una sola location, semántica o built-in.

En inglés (idioma base del analizador): *Conflicting interface attributes*: '`…`' has both [`…`] and [`…`]. An interface member carries a single location, semantic or built-in.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.SlotConflict`).
