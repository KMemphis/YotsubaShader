# YS0209: Location en un compute shader

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' tiene [`…`], pero un compute shader no tiene entradas ni salidas por location; solo built-ins como SV_DispatchThreadID.

En inglés (idioma base del analizador): *Location in a compute shader*: '`…`' has [`…`], but a compute shader has no location inputs or outputs; only built-ins such as SV_DispatchThreadID.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.LocationInCompute`).
