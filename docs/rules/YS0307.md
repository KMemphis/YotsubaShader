# YS0307: Tipo no válido en un buffer

| | |
|---|---|
| Severidad | Error |
| Área | Recursos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' en el buffer '`…`' es '`…`': `…`.

En inglés (idioma base del analizador): *Type not valid in a buffer*: '`…`' in the buffer '`…`' is '`…`': `…`.

## Contexto

Texturas, samplers y buffers: bindings y layout de memoria.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.BufferMemberType`).
