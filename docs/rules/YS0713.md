# YS0713: Uniform buffer demasiado grande

| | |
|---|---|
| Severidad | Warning |
| Área | Portabilidad |
| Categoría | YotsubaShader.Portability |

## Mensaje

> El uniform buffer '`…`' ocupa `…` bytes (std140), más de lo que garantiza `…`. Afecta a: `…`.

En inglés (idioma base del analizador): *Uniform buffer too large*: The uniform buffer '`…`' takes `…` bytes (std140), more than what is guaranteed by `…`. Affects: `…`.

## Contexto

Funciona en unas APIs y no en otras; se valida contra las APIs de [ShaderTargets] (Vulkan 1.3 si el shader no declara ninguna).

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0713.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.UniformBufferTooLarge`).
