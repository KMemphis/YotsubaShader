# YS0215: Entrada de fragment sin salida de vertex

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> La entrada '`…`' (`…`) de '`…`' no la escribe ninguna salida del vertex shader '`…`'.

En inglés (idioma base del analizador): *Fragment input without a vertex output*: The input '`…`' (`…`) of '`…`' is not written by any output of the vertex shader '`…`'.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.FragmentInputWithoutVertexOutput`).
