# YS0008: [VectorComponent] ignorado

| | |
|---|---|
| Severidad | Warning |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> [VectorComponent] en '`…`' se ignora: un componente debe ser un campo o propiedad de instancia.

En inglés (idioma base del analizador): *[VectorComponent] ignored*: [VectorComponent] on '`…`' is ignored: a component must be an instance field or property.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0008.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorComponentIgnored`).
