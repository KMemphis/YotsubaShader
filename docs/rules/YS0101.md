# YS0101: Compute shader sin tamaño de grupo

| | |
|---|---|
| Severidad | Error |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> El compute shader '`…`' necesita un tamaño de grupo: añade [numthreads(x, y, z)], [layout_local_size(...)] o [workgroup_size(...)].

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.ComputeWithoutWorkgroupSize`).
