# YS0201: Built-in no válido en esta etapa

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> [`…`] (`…`) no existe en un shader `…`. Se usa en: `…`.

En inglés (idioma base del analizador): *Built-in not valid in this stage*: [`…`] (`…`) does not exist in a `…` shader. It is used in: `…`.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.BuiltInWrongStage`).
