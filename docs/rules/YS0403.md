# YS0403: Parámetro params en un shader

| | |
|---|---|
| Severidad | Error |
| Área | Métodos |
| Categoría | YotsubaShader |

## Mensaje

> El parámetro '`…`' de '`…`' es params; usa un array de longitud fija.

En inglés (idioma base del analizador): *params parameter in a shader*: The parameter '`…`' of '`…`' is params; use a fixed-length array.

## Contexto

Funciones auxiliares que se compilan a la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.ParamsParameter`).
