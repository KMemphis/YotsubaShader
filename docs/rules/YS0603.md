# YS0603: Escritura en una entrada

| | |
|---|---|
| Severidad | Error |
| Área | Uso por etapa |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es una entrada del shader y no se puede modificar. Cópiala a una variable local.

## Contexto

Operaciones que solo existen en una etapa del pipeline.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.WriteToInput`).
