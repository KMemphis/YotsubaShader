# YS0501: Sentencia no soportada

| | |
|---|---|
| Severidad | Error |
| Área | C# sin traducción |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' no existe en la GPU. `…`

En inglés (idioma base del analizador): *Unsupported statement*: '`…`' does not exist on the GPU. `…`

## Contexto

Construcciones de C# que no existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.UnsupportedStatement`).
