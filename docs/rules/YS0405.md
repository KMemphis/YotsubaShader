# YS0405: Llamada virtual

| | |
|---|---|
| Severidad | Error |
| Área | Métodos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es `…`; en la GPU solo hay llamadas directas a métodos concretos.

En inglés (idioma base del analizador): *Virtual call*: '`…`' is `…`; on the GPU there are only direct calls to concrete methods.

## Contexto

Funciones auxiliares que se compilan a la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VirtualCall`).
