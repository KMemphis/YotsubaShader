# YS0009: [VectorComponent] fuera de un vector

| | |
|---|---|
| Severidad | Warning |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' tiene [VectorComponent] pero el tipo '`…`' no está marcado con [Vector].

En inglés (idioma base del analizador): *[VectorComponent] outside a vector*: '`…`' has [VectorComponent] but the type '`…`' is not marked with [Vector].

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0009.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorComponentOutsideVector`).
