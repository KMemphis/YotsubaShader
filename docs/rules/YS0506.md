# YS0506: switch sin caso por defecto

| | |
|---|---|
| Severidad | Error |
| Área | C# sin traducción |
| Categoría | YotsubaShader |

## Mensaje

> La expresión switch no cubre todos los valores. Añade un brazo '_ => ...'.

En inglés (idioma base del analizador): *switch without a default case*: The switch expression does not cover all values. Add a '_ => ...' arm.

## Contexto

Construcciones de C# que no existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.SwitchNotExhaustive`).
