# YS0217: Descriptor en la interfaz

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' tiene [`…`], que es para recursos (texturas, samplers, buffers), no para entradas o salidas.

En inglés (idioma base del analizador): *Descriptor in the interface*: '`…`' has [`…`], which is for resources (textures, samplers, buffers), not for inputs or outputs.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.DescriptorOnInterface`).
