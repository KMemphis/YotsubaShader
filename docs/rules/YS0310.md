# YS0310: Campo sin significado en la GPU

| | |
|---|---|
| Severidad | Error |
| Área | Recursos |
| Categoría | YotsubaShader |

## Mensaje

> El campo '`…`' no es un recurso. Para pasar valores desde la CPU agrúpalos en un struct con [Uniform] y [Binding].

En inglés (idioma base del analizador): *Field with no meaning on the GPU*: The field '`…`' is not a resource. To pass values from the CPU, group them in a struct with [Uniform] and [Binding].

## Contexto

Texturas, samplers y buffers: bindings y layout de memoria.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.PlainFieldInShader`).
