# YS0221: Vertex shader sin posición

| | |
|---|---|
| Severidad | Warning |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> El vertex shader '`…`' no escribe SV_Position; la GPU no podrá rasterizar sus primitivas.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0221.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `<YotsubaShaderTargets>` en el `.csproj`.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VertexWithoutPosition`).
