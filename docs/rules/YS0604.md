# YS0604: Atómica sobre una variable local

| | |
|---|---|
| Severidad | Error |
| Área | Uso por etapa |
| Categoría | YotsubaShader |

## Mensaje

> La operación atómica '`…`' necesita un campo de un storage buffer como destino.

## Contexto

Operaciones que solo existen en una etapa del pipeline.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.AtomicTarget`).
