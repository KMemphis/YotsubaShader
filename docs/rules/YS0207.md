# YS0207: Miembro de la interfaz sin slot

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es `…` de '`…`' y no tiene location, semántica ni built-in. Añade por ejemplo [TEXCOORD(n)], [location(n)] o un built-in.

En inglés (idioma base del analizador): *Interface member without a slot*: '`…`' is `…` of '`…`' and has no location, semantic or built-in. Add for example [TEXCOORD(n)], [location(n)] or a built-in.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.MissingSlot`).
