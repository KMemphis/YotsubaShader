# YS0214: Recurso en la interfaz

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es `…` y no puede pasar entre etapas. Decláralo como campo del shader con [Binding].

En inglés (idioma base del analizador): *Resource in the interface*: '`…`' is `…` and cannot be passed between stages. Declare it as a shader field with [Binding].

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.ResourceInInterface`).
