# YS0212: Semántica en una salida de fragment

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' usa [`…`] como salida de un fragment shader. Las salidas de fragment son render targets: usa [SV_Target(n)] o [location(n)].

En inglés (idioma base del analizador): *Semantic in a fragment output*: '`…`' uses [`…`] as the output of a fragment shader. Fragment outputs are render targets: use [SV_Target(n)] or [location(n)].

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.SemanticInFragmentOutput`).
