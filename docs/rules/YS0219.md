# YS0219: Built-in no soportado todavía

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> [`…`] (`…`) todavía no está soportado por el compilador de YotsubaShader.

En inglés (idioma base del analizador): *Built-in not supported yet*: [`…`] (`…`) is not supported by the YotsubaShader compiler yet.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.BuiltInNotSupported`).
