# YS0707: Operación con derivadas en control de flujo no uniforme

| | |
|---|---|
| Severidad | Warning |
| Área | Portabilidad |
| Categoría | YotsubaShader.Portability |

## Mensaje

> '`…`' está dentro de un `…` cuya condición depende de una entrada del shader. Es un error en WGSL y da resultados indefinidos en las demás APIs. Afecta a: `…`.

## Contexto

Funciona en unas APIs y no en otras; se avisa según YotsubaShaderTargets.

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0707.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `<YotsubaShaderTargets>` en el `.csproj`.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.NonUniformDerivative`).
