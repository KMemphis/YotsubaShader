# YS0707: Operación con derivadas en control de flujo no uniforme

| | |
|---|---|
| Severidad | Warning |
| Área | Portabilidad |
| Categoría | YotsubaShader.Portability |

## Mensaje

> '`…`' está dentro de un `…` cuya condición depende de una entrada del shader. Es un error en WGSL y da resultados indefinidos en las demás APIs. Afecta a: `…`.

En inglés (idioma base del analizador): *Derivative operation in non-uniform control flow*: '`…`' is inside a `…` whose condition depends on a shader input. It is an error in WGSL and gives undefined results in the other APIs. Affects: `…`.

## Contexto

Funciona en unas APIs y no en otras; se valida contra las APIs de [ShaderTargets] (Vulkan 1.3 si el shader no declara ninguna).

Es una alerta: el shader compila, pero puede fallar o comportarse distinto en alguna API o GPU. Se puede ajustar con `.editorconfig` (`dotnet_diagnostic.YS0707.severity`) y, para las alertas de portabilidad, eligiendo las APIs con `[ShaderTargets(...)]` en la clase o el ensamblado. Si el shader declara una API que no tiene lo que usa, la alerta pasa a ser un error.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.NonUniformDerivative`).
