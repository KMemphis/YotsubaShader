# YS0505: Campo estático mutable

| | |
|---|---|
| Severidad | Error |
| Área | C# sin traducción |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es un campo estático que no es constante. La GPU no tiene estado global mutable; usa 'const' o un recurso.

En inglés (idioma base del analizador): *Mutable static field*: '`…`' is a static field that is not constant. The GPU has no mutable global state; use 'const' or a resource.

## Contexto

Construcciones de C# que no existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.MutableStaticField`).
