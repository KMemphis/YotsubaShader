# YS0006: Tipo de componente no soportado

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> El componente '`…`' es de tipo '`…`'. Los vectores admiten bool, short, ushort, int, uint, Half, float y double.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorComponentType`).
