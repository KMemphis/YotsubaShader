# YS0507: Array no soportado

| | |
|---|---|
| Severidad | Error |
| Área | C# sin traducción |
| Categoría | YotsubaShader |

## Mensaje

> `…`. En la GPU los arrays tienen una dimensión y una longitud constante.

En inglés (idioma base del analizador): *Unsupported array*: `…`. On the GPU arrays have one dimension and a constant length.

## Contexto

Construcciones de C# que no existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.UnsupportedArray`).
