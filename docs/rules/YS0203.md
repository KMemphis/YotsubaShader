# YS0203: Tipo incorrecto para el built-in

| | |
|---|---|
| Severidad | Error |
| Área | Interfaz entre etapas |
| Categoría | YotsubaShader |

## Mensaje

> [`…`] (`…`) debe ser `…`, pero '`…`' es '`…`'.

En inglés (idioma base del analizador): *Wrong type for the built-in*: [`…`] (`…`) must be `…`, but '`…`' is '`…`'.

## Contexto

Entradas y salidas de cada etapa: built-ins, locations y semánticas.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.BuiltInWrongType`).
