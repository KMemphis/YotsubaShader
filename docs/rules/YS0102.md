# YS0102: Tamaño de grupo inválido

| | |
|---|---|
| Severidad | Error |
| Área | Puntos de entrada |
| Categoría | YotsubaShader |

## Mensaje

> La dimensión `…` del tamaño de grupo de '`…`' es `…`; cada dimensión debe ser al menos 1.

## Contexto

Métodos con [ShaderStage]: forma, etapa y tamaño de grupo de compute.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.WorkgroupSizeZero`).
