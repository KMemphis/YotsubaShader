# YS0001: Número de componentes inválido

| | |
|---|---|
| Severidad | Error |
| Área | Tipos de GPU |
| Categoría | YotsubaShader |

## Mensaje

> El vector '`…`' tiene `…` componentes; un vector de GPU tiene entre 2 y 4. Ajusta los campos [VectorComponent].

En inglés (idioma base del analizador): *Invalid component count*: The vector '`…`' has `…` components; a GPU vector has between 2 and 4. Adjust the [VectorComponent] fields.

## Contexto

Cómo se declaran vectores y qué tipos existen en la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.VectorComponentCount`).
