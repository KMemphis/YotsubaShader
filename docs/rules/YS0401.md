# YS0401: Método genérico en un shader

| | |
|---|---|
| Severidad | Error |
| Área | Métodos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es genérico; los shaders no tienen genéricos. Escribe una versión por tipo.

## Contexto

Funciones auxiliares que se compilan a la GPU.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.GenericMethod`).
