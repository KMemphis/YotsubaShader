# YS0304: Registro HLSL de otro tipo

| | |
|---|---|
| Severidad | Error |
| Área | Recursos |
| Categoría | YotsubaShader |

## Mensaje

> '`…`' es `…` y usa el registro '`…`'; para este recurso el prefijo es '`…`'.

En inglés (idioma base del analizador): *HLSL register of another kind*: '`…`' is `…` and uses the register '`…`'; the prefix for this resource is '`…`'.

## Contexto

Texturas, samplers y buffers: bindings y layout de memoria.

Un error YS significa que el shader no compilaría para la GPU: el compilador de YotsubaShader lo rechaza con el mismo código, así que lo que el IDE acepta compila.

## Cómo se arregla

El propio mensaje indica la corrección. Las reglas se implementan en `Core/Analyzers/YotsubaShader.Rules` (descriptor `ShaderRules.RegisterKindMismatch`).
